COMO EJECUTAR EL PROGRAMA
------------------------------------------------------------------------
WINDOWS  (Prototipo1_v2.12.zip)
  1. Descomprimir el ZIP.
  2. Entrar a la carpeta "Prototipo1".
  3. Doble clic en "Prototipo1.exe".
  4. Si aparece el aviso SmartScreen ("Windows protegio tu PC"):
     "Mas informacion" -> "Ejecutar de todas formas". El ejecutable no
     esta firmado, pero es seguro.

macOS  (Prototipo1_Mac.zip)
  Requiere Python 3 instalado.
  1. Descomprimir el ZIP.
  2. Abrir la Terminal.
  3. Escribir  bash  y un espacio, arrastrar el archivo "run.command" de
     la carpeta descomprimida, y presionar Enter.
  4. La primera vez crea el entorno e instala dependencias (unos minutos).

Una vez abierto, se puede cargar "ejemplo.room" para ver un caso listo.
El manual de usuario (Manual_de_Usuario.txt) explica el flujo completo.
